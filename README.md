# omegalpes_tutorial
Welcome to OmegAlpes Tutorial !

You can start the tutorial by running OmegAlpes_tutorial.ipynb! Hope you enjoy your journey !! 

Jupyter notebook installation instruction : https://omegalpes-examples.readthedocs.io/en/latest/jupyter.html#


## What you will learn

You play an energy consultant helping a client, John, with his home energy system:

1. Energy balance: model consumption, PV production and grid import/export, and minimize grid import
2. Storage and shiftable loads: add a battery and a washing machine and see how the optimizer shifts demand
3. Heat and electricity: couple a water heater and a hot-water tank to the electrical system
4. Cost comparison: choose between two grid suppliers with hourly prices

## How it is designed

- Sub-goal worked examples: each tutorial is split into small, labeled steps with a table of contents
- Practice with instant feedback: quizzes and hint buttons after each tutorial
- Gamification: a skill-tree dashboard (level 1 and level 2 tutorials), a story-based case and a final "magic sentence" challenge
- Links from each step to the OMEGAlpes documentation
